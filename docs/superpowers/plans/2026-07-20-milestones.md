# Infini-Transeon 里程碑与关键路径

**日期：** 2026-07-20
**状态：** 已确认。全功能 v1 单次公开发布是既定决策；本文档把开发阶段组织为内部垂直切片里程碑，只影响内部推进与验证节奏，不改变对外发布策略。

任务编号引用：后端 = `2026-07-19-backend-implementation-plan.md`（Task 0–16），前端 = `2026-07-19-frontend-implementation-plan.md`（Task 0–14）。

## M0 — 平台边界验证

**内容：** 后端 Task 0（捕获边框、捕获排除、热键送达）、前端 Task 0（托盘、焦点、覆盖消息、IPC）、后端 Task 1（合同、IPC、fakes、信任根 schema）。

**退出标准：**
- 两份 spike 结论已落档，WGC 边框关闭（`IsBorderRequired` + `RequestAccessAsync` 用户授权流程，含拒绝授权与重启持久性）已实测并回写产品沉浸感合同；安装版与便携版都已证明可在普通用户权限下建立、升级与清理 package identity，且 manifest 声明 `graphicsCaptureWithoutBorder`；
- 架构规格若与 spike 结论冲突已完成修订；
- ABI/IPC golden 合同测试与架构测试全绿；便携版若无法可靠获得无边框捕获能力，M0 不得退出，必须先修订分发合同。

**未通过的后果：** 不得开始后端 Task 3/11 与任何前端 UI 正式任务。

## M1 — 单目标最小纵切

**内容：** 后端 Task 2、3、4、5（基础调度）、6（本地 OCR）、7、8 的 OpenAI 兼容子集、9 的单通道子集、11（基础覆盖）；前端 Task 1–5（探针走 fakes，按门槛切真实现）。

**退出标准：**
- 单窗口 + 单通道端到端：捕获→检测→OCR→翻译→固定槽位覆盖，游戏不失焦；
- 30 分钟运行内存/队列有界（产品验收场景 1 的单目标子集）；
- P0 本机未缓存路径 P95 < 300 ms 候选门槛首次实测记录。

## M2 — 多目标与翻译通道完整

**内容：** 后端 Task 5（完整二维调度）、8（完整提供商矩阵，含声明式 REST 引擎与逐提供商 fit 审计）、9（完整 1–4 通道 + 润色 + fallback）、10、12；前端 Task 6、7、8（术语表/风格提示词）、9（覆盖样式）、10（托盘/热键）。

**退出标准：**
- 产品验收场景 1–6 全部通过；
- 令牌层级拒旧结果（验收场景 11 的非重启子集）通过；
- **封闭测试圈启动**：小范围受邀测试（不称 Alpha/Beta、不公开分发），专门收集游戏字体、DPI/多显示器、驱动、反作弊共存数据；建立反馈模板与已知兼容性清单。

## M3 — 数据、体验与无障碍完备

**内容：** 后端 Task 13；前端 Task 11（历史）、12（设置/本地模型 UI/导入导出）、13（诊断）。

**退出标准：**
- 产品验收场景 8、9 通过；
- en-US + zh-CN 全量字符串、键盘、高对比度、200% 缩放、Narrator 扫描全绿；
- 历史关闭/开启的隐私不变量测试（架构规格 §14 条 8、12）通过。

## M4 — 发布工程与门槛校准

**内容：** 后端 Task 14（ModelWorker，含运行时裁决与沙箱断网验证）、15（签名更新与打包）、16（基准、隐私、端到端门槛）；前端 Task 14。

**退出标准：**
- 产品验收场景 1–12 全部通过；
- 候选性能与 OCR 质量门槛完成硬件矩阵校准并固化（模型选型评审状态改为"已校准"）；
- 签名链演练：正式密钥签发、防降级状态、便携包 manifest 验证、双密钥轮换预案各走一遍；
- 封闭测试圈的兼容性问题清零或明确豁免并写入已知问题。

## 关键路径与并行度

```text
串行主干（后端）：Task 0 → 1 → 3 → 5 → 6 → 7 → 9 → 11 → 16
可并行支线：
  Task 2（档案）        与 Task 3 并行
  Task 4（几何）        紧随 Task 3
  Task 8（提供商）      自 Task 1 后与 5–7 并行（依赖声明式 schema 先行）
  Task 10/12/13         自其依赖任务后并行
  Task 14/15            M4 前独立推进
前端：Task 0 后全线基于 Task 1 fakes 并行；真实集成按后端 Task 3/6/8/11 门槛切换。
```

主干上任何任务的延期直接推迟发布；支线延期只压缩并行窗口。进度评审以主干为准。

## 约束重申

- 里程碑不是范围裁剪：所有已确认功能仍属 v1，M1–M3 的"子集"仅指实现顺序。
- 每个里程碑退出标准未满足前，不进入下一里程碑的主干任务；支线任务可预研。
- 封闭测试圈不构成公开发布，不使用 Alpha/Beta 称谓，分发物仍需签名。
