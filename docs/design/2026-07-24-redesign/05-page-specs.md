# 5. 逐页规格与文字线框

通用约定(所有页适用,不再逐页重复):

- **页面骨架:** 统一 `PageShell` 组件(第 8 章):页头(标题/副标题/命令区)+ 内容区 + 统一的加载(骨架屏或 ProgressBar)/错误(InfoBar+重试按钮)/空状态插槽。
- **响应式:** 桌面(≥1120)完整布局;紧凑(820–1119)侧栏收窄、多列降双列;窄(600–819)单列堆叠、侧栏 LeftCompact。<600 不支持(窗口最小 960×600,窄态仅覆盖用户手动贴边分屏)。本产品无移动/平板目标平台,"窄窗"即为最小体验,此为平台事实而非省略。
- **权限态:** 捕获授权缺失、离线模式、凭据缺失均以页内 InfoBar + 行内徽标呈现,永不静默禁用。
- **保存模型:** 工作区各配置节共享粘性底部保存栏(出现于脏状态):`未保存更改 · [放弃] [保存并应用]`,保存后 250ms 内显示 Applying → 引擎确认后 Applied(遵守前端计划约束)。

## 5.1 Home(启动台)

- **目的:** 最高频任务"启动并去玩"一步完成;运行状态与需处理错误一眼可见。
- **主要任务:** 启动/停止/暂停档案;进入档案工作区;新建/导入档案;瞥见最近活动。
- **替代:** ProfileCenterPage + RunningTargetsPage。

```text
┌────────────────────────────────────────────────────────────────┐
│ Home                                    [导入] [＋ 新建档案]   │
├────────────────────────────────────────────────────────────────┤
│ ▶ 正在运行(有运行时显示)                                      │

│ └────────────────────────────────────────────────────────────┘ │
│ 档案                                                            │
│ ┌──────────┐ ┌──────────┐ ┌──────────┐                        │
│ │ 缩略图    │ │ 缩略图    │ │  ＋      │                        │
│ │ 原神 ●运行│ │ P5R ✓就绪│ │ 新建档案 │                        │

└────────────────────────────────────────────────────────────────┘
```

- **区域与层级:** 运行面板(仅运行时出现,置顶)> 档案网格(UniformGrid,MinItemWidth 320)> 活动摘要(最近 3 条 Warning+ 事件)。
- **主动作:** 档案卡 `▶ 启动`(就绪时)/`修复`(未就绪时,直达缺失项所在分节);运行面板行内 暂停/覆盖/手动识别/停止。
- **次动作:** 卡片点击主体 → 工作区概览;溢出菜单:导出、复制、置顶、删除(确认对话框,输入档案名确认为 P3 增强)。
- **档案卡状态徽标:** `●运行中(Success)` `⏸已暂停(Warning)` `✓就绪(Neutral)` `⚠需处理(Critical,附原因短语:凭据缺失/目标未找到/草稿)`。
- **缩略图:** 引擎运行时用受控低频缩略图(既有 `RequestThumbnailAsync`);未运行时用上次运行缓存的缩略图;从未运行显示目标类型图标。彻底消灭恒占位符。
- **空态:** 无档案 → 全页引导态(插图 + "创建第一个档案" + "导入");等同现 ProfileCenter 空态但整页化。
- **加载:** 档案卡骨架屏 ×3。
- **错误:** 页级 InfoBar + 重试;启动失败错误落在对应档案卡上(行内红字 + "查看详情")而非全局。
- **数据:** `ProfileStore.Cards`(含运行状态投影)、`RuntimeStore.RunningTargets`、`ActivityStore.Recent(3, minSeverity: Warning)`。
- **组件:** PageShell、ProfileCard(重构)、RunningTargetBar(新)、ActivityListItem、EmptyState。

## 5.2 新建档案引导流(/profiles/new)

- **目的:** 首次成功率最大化;每步实测、步步可退、可存草稿。替代 SetupWizardPage。
- **布局:** 全屏(隐藏侧栏),顶部**可点击步骤条**(已完成步可回跳,未到达步禁用),底部导航栏(上一步/下一步/存草稿)。
- **步骤与门禁(Next 由本步校验解锁,禁用时显示缺失原因 tooltip):**

| 步 | 名称 | 内容 | 门禁 | 实测 |
|---|---|---|---|---|
| 1 | 捕获目标 | 档案名 + 目标多选列表(实时探测)+ 桌面固定区域(屏幕上直接框选,数字框为辅) | 名称非空 + ≥1 目标 | 目标缩略图预览 |
| 2 | 语言与服务 | 源/目标语言 + 初始翻译器选择 + 凭据(行内状态:已存/缺失 → 凭据对话框) | 语言有效且不同 + 翻译器已选且凭据就绪 | "测试翻译"按钮:发一句样例文本,显示延迟与结果 |
| 3 | 翻译区域 | **复用工作区画布组件**(目标预览 + 绘制),右侧简化检查器(仅名称/优先级/上下文角色) | ≥1 有效区域 | 区域内"试跑 OCR"按钮,显示识别文本 |
| 4 | 测试并保存 | 摘要 + 就绪清单(实时,可点击跳回对应步)+ 覆盖预览(OverlayPreviewRenderer) | 全部就绪 | [保存并启动] / [仅保存] / [存草稿](任何时刻可用) |

- **草稿:** 顶部"存草稿并退出"常驻;草稿档案在 Home 显示"草稿"徽标,点击回到中断步。
- **错误/失败:** 每步实测失败停留原步,InfoBar 给出修复动作(如"打开提供商页配置凭据"深链)。
- **窄窗:** 步骤条折叠为 `2/4 语言与服务` 计步器。
- **数据:** 复用 `ProfileWorkspaceStore` 草稿模型(与工作区同一模型,消灭双重建模);探测走既有 `ICaptureProbe`/`ITranslationProbe`/`IOcrProbe`(后端探针已存在,当前向导未用足)。

- **检查器仅剩:** 基本(5 控件)+ OCR(4 控件)+ 布局与换行(整行策略 4 控件 + 几何 4 数字框)。通道/覆盖/性能移出(见 5.5/5.6;区域级性能参数"识别间隔/检测缩放"移入 OCR 组底部"高级"折叠)。

- **空态:** "此区域尚未启用翻译" + 开关 + 添加第一条通道。
- **数据:** `ProfileWorkspaceStore.SelectedRegion.Channels`;提供商目录来自 `ProviderStore`(含就绪状态)。

- **布局:** 三张并列卡(桌面)/堆叠(窄):**游戏语境**(游戏名/描述/最近行数——现藏于 WorkbenchViewModel 无 UI 归属)、**术语表**、**风格提示词**。

## 5.8 工作区 · 历史(/profiles/{id}/history)与全局活动(/activity)

- **历史(档案内):** 按日期分组的事件列表;事件卡 = 时间/区域 + 原文 + 通道结果网格(保留现多通道对比布局);**新增"保存修正"**:任一结果卡的 ✏ 按钮 → 行内编辑译文 → `[仅保存修正]` / `[并加入术语表]`(带作用域说明)。[假设:修正语义见 02-§2.5]
- **活动(全局):** 三个 SelectorBar 视图:**事件流**(实时推送,严重度/作用域/档案筛选,替代静态诊断页)、**跨档案历史**(同历史组件,多一列档案名)、**报告**(导出诊断 JSON、打开崩溃目录、内存转储开关入口)。
- **实时性:** 事件流由内存事件总线推送(第 7 章),顶部"实时"徽标;历史仍为查询式。
- **空态:** 事件流空 → "一切正常,尚无事件";历史关闭时保留现 `HistoryDisabledBar` 模式并链接到设置。

## 5.9 提供商与模型(/providers)

- **布局:** 页顶横幅区(离线模式开启时:"严格离线模式已开启——云提供商、模型下载与更新已禁用 [前往设置]")+ 分组列表:**云翻译 / 云 OCR / 本地模型 / 自定义 REST 适配器**(现为混排一列)。
- **提供商卡:** 名称/类型/状态徽标 + **行内端点编辑**(从凭据对话框迁出)+ [配置凭据](瘦身后的对话框)+ 模型安装/移除(保留进度条与取消)。
- **空态:** 自定义适配器组空 → "导入 REST 适配器定义" 引导。
- **凭据对话框:** 保留 PasswordBox/服务账号 JSON 导入/自动化名称/内存清除;移除端点字段。

## 5.10 设置(/settings)

- **布局:** 左列分节导航(SelectorBar 垂直)+ 右列内容;顶部设置内搜索(过滤高亮匹配的设置行)。
- **分节:** 外观与语言(主题/应用语言(资源化,修复硬编码)/格式区域/减少动画)、热键(表格化:动作/手势/作用域/状态/启用;冲突行内红字;恢复默认)、隐私与数据(离线模式(注明影响面)/历史保留/翻译记忆同意/崩溃转储)、性能(预设 + 与区域锁定关系说明)、关于与更新(版本/检查/下载,签名状态行内前置而非只在对话框)。
- **热键作用域列:** 全部目标/前台匹配/指定组(产品 §3.3)。[假设:编辑器交互为下拉]

## 5.11 对话框、抽屉与覆盖面收敛原则
