# 6. 核心用户流(现状 vs 新流程)

## 6.1 日常启动并去玩(最高频)

**现状(且无法完成关窗):**
1. 打开应用 → 档案中心 2. 找到档案卡点"启动" 3. 跳转运行目标页 4. 确认状态 5. **窗口必须保持打开**(关窗即停止引擎)。
**新流程:**
1. 打开应用 → Home 2. 档案卡 `▶ 启动` 3. 关窗 → 自动托盘化,引擎继续。
**步数:** 5(含一个不可能步)→ 3。失败路径:启动失败错误落在该档案卡行内,附"查看详情"(深链到活动页对应事件)与"重试";凭据缺失直接给"修复"深链。

## 6.2 游戏中暂停/切换翻译器组

**现状:** 仅热键(功能存在);无托盘;若要用 UI 必须 Alt-Tab 出游戏(违背产品红线)。
**新流程:** 热键(保留)或托盘菜单(新增,非激活操作)。UI 反馈 = 覆盖层角落短暂提示(引擎侧已有规格)。零窗口交互。
**数据变更:** `SetPausedAsync` 等 → 乐观 Pending 态(托盘图标即时变化)→ 引擎确认/回滚。

## 6.3 新游戏建档(首次成功关键路径)

**现状:** 8+ 步且多断点:新建 → 步 1(无预览)→ 步 2(凭据对话框,无校验反馈)→ 步 3(仅命名区域,**无绘制**)→ 步 4 才发现未就绪 → 回头补 → 保存并启动 → 跳运行页 → 实际覆盖效果未知,需再进工作台画区域。
**新流程:** 新建 → 步 1 选目标(带缩略图确认)→ 步 2 语言+翻译器(行内凭据状态,"测试翻译"即时验证)→ 步 3 **直接在预览上绘制区域** + 试跑 OCR → 步 4 覆盖预览确认 → 保存并启动 → 完成即可玩。
**步数:** 有效步 4,且每步内闭环验证;消灭"保存后再进工作台补画区域"的整段返工(约省 5–8 次交互)。
**决策点:** 步 2 选云 or 本地翻译器(本地未安装 → 提示到提供商页,草稿保留);步 3 全窗口扫描 vs 手绘区域。
**失败恢复:** 每步实测失败停在原步 + 修复动作;随时存草稿;草稿在 Home 可继续。

## 6.4 微调运行中档案的覆盖样式

**现状:** 档案中心 → 卡片"编辑" → 工作台 → 右栏找到"Overlay"折叠区展开 → 6 控件挤在 320px → 保存(全档案校验)→ InfoBar 告知 HotApplied/Restarted。字号/描边等控件已随页面删除丢失。
**新流程:** Home → 档案卡 → 工作区"覆盖样式" → 360px 专属控件列 + 实时预览(可切结果状态)→ 粘性栏"保存并应用" → Applying → Applied(热应用徽标)。
**步数:** 6 → 4;关键提升是**预览所见即所得**与恢复丢失控件,不只是步数。

## 6.5 游戏后修正一句错译

**现状:** 不可能(历史只有复制)。
**新流程:** Home 活动摘要或工作区历史 → 找到事件卡 → 结果卡 ✏ → 行内改译文 → [并加入术语表](可改词条粒度)→ 完成。后续该词自动生效(重译当前文本由既有热键触发)。
**验证/安全:** 修正不回写已显示结果(产品红线);保存时明示作用域"仅影响今后的翻译"。

## 6.6 配置新提供商凭据

**现状:** 服务与模型页 → 卡片"Configure" → 对话框(凭据+端点混杂)→ 保存 → 整页重载;离线模式导致的失败无解释。
**新流程:** 提供商页(离线时页顶横幅先行解释)→ 分组找到提供商 → 端点行内直改;凭据走瘦身对话框 → 保存 → 该卡行内状态即时更新(不整页重载)。
**通知:** 凭据过期/无效在档案就绪清单与 Home 卡片"需处理"徽标中浮现(现状完全无此回路)。

## 6.7 排查"为什么翻译停了"

**现状:** 诊断页静态列表(磁盘 JSONL 一次性读取,`RecoveryAction` 恒为 "—"),需要重进页面刷新;严重度无筛选。
**新流程:** 托盘徽标变色 → 打开应用,Home 活动摘要置顶该错误 → 点击进入活动页事件流(实时)→ 事件卡含当前行为 + 恢复动作按钮(如"重试通道"/"打开提供商页")。
**步数:** 猜测式排查 → 3 步定向。

## 6.8 权限/授权相关流

- **捕获边框授权(包身份可用时):** 首次启动引导流中请求 `GraphicsCaptureAccess.RequestAccessAsync`;被拒 → 概览就绪清单显示"系统捕获边框将保留"信息项(非阻断,符合产品 §5.10 披露要求)。
- **无包身份(GitHub 便携版):** 同位置常显信息徽标,文案说明边框保留,绝不宣称无痕。
- **离线模式:** 所有受影响表面(提供商横幅、更新节、云 OCR 开关)一致引用同一说明组件。
